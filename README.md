# 1tbBOT
Bot na serwer discord klasy 1tb

## Instalacja:
1. Sklonuj repozrytorium:
```git clone https://github.com/Alkozaur/1tbBOT```
2. Zainstaluj zależności:
```pip install -r requirements.txt```
3. Dodaj plik CHANEL.txt, dopisz do niego ID kanału, na którym mają być wysyłane ogłoszenia.
4. Dodaj plik TOKEN.txt i dopisz do niego token bota.
